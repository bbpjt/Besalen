Pusat Ekspor Geospasial (QGIS & ArcGIS)

Seluruh data titik koordinat dan batas wilayah dapat diunduh dalam format standar OGC untuk dianalisis di QGIS, ArcGIS Pro, atau web mapping.

1. GeoJSON Titik Sastra Lisan (WGS84)

Format standar RFC 7946 memuat seluruh 91 titik sastra lisan (Ring 1, 2, 3) beserta atribut lengkap.

2. CSV Geospasial dengan Kolom WKT

Format tabel CSV dengan kolom Latitude, Longitude, dan WKT POINT(lng lat) untuk menu Add Delimited Text Layer di QGIS.

3. GeoJSON Batas 35 Kab/Kota + Agregat

Layer poligon administratif se-Jawa Tengah yang memuat atribut rekapitulasi jumlah sastra lisan untuk peta tematik choropleth.
